# Исследование АКБ квадроцикла — редакция 11, 30.09.2026

Сайт: https://ai-motor-ufa.github.io/electric-atv-battery/

Обновление: 23 графика 21700 пользователя, приближённое интегрирование энергии до 2,8/3,0 В, температуры с начальных около 25 °C; 16 предложений Vapcell/Alibaba в USD с отдельными статусами. Фото нового рейтинга относится к 18650 и показано отдельно. Идентичности JP50/JP50P1, 50P/50T, Yichuan/EVE и Vapcell G50/T60/Q65 не смешиваются.

Для совпадающих моделей напряжение интерполируется по V(Ah,I); потеря DCIR не вычитается из измеренного напряжения повторно. Без кривых остаётся общая OCV. Тепловая модель остаётся сценарной: G стендовой ячейки не перенесён в герметичный блок. Добавлены потери обвязки внутри корпуса, Tmax, остановка при 60 °C и G=0. Производители описаны непосредственно в рейтинговых карточках со ссылками.

Исходники новых данных: `discharge_tests.json`, `alibaba_quotes.json`. `digitize_discharge.py` воспроизводит растровое извлечение из архива, размещённого в соседней директории `discharge-charts`; SHA-256 оригиналов записаны в JSON. Неполная оцифровка не выдаётся за полную энергию. Некоторые кривые имеют конфликт легенды либо температурную остановку.

Сборка: `python3 adaptive_model.py`, `python3 test_sections.py`, `python3 build_report.py`, `python3 build_release.py`. Проверки: `python3 validate_model.py`, `node validate_interactions.cjs`, `node validate_mooch.cjs`, `python3 validate_discharge.py`.

PDF и статические файлы публикуются из `dist` через GitHub Pages. Маркер выпуска `20260930-r11`, контрольные суммы — `dist/release.json`. Новые CSV — UTF-8 BOM, разделитель `;`. Прежние выгрузки Mooch/NKON сохранены с исходными датами и охватом.
