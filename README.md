# Исследование АКБ квадроцикла, редакция 4

Статический сайт и соответствующий PDF с одним набором исходных данных.

- `data.json`, `new_cells.json`: паспортные данные и источники.
- `adaptive_model.py`: расчёт мощности, энергии и усреднённой температуры при ограничениях по SOC, напряжению и температуре; результат `calculated.json`.
- `report_content.py`: общая методика и выводы.
- `build_report.py`: создаёт HTML и PDF из этих данных.
- `dist/report.js`, `dist/report.css`: сортировка, сравнение, графики и оформление.
- `photos.json`: происхождение и подписи фотографий.

Пересчёт: `python3 adaptive_model.py`, затем Python с ReportLab: `python3 build_report.py`.
Проверки: `python3 validate_model.py` и `node validate_interactions.cjs`.

Модель служит предварительному отбору. Она не воспроизводит скоростную трассу WMTC и не заменяет тепловое испытание закрытого блока. Отсутствующий DCIR не заменяется ACIR.

Сайт публикуется из `dist` через Sites. Браузерная проверка в управляемой среде недоступна для текущего статического проекта без совместимого dev-сервера; интерактивность проверяется через изолированное исполнение JavaScript, PDF — рендерингом всех страниц.

## GitHub Pages

Workflow `.github/workflows/pages.yml` публикует содержимое `dist` после каждого push в `main`. В настройках репозитория нужно выбрать `Settings → Pages → Source: GitHub Actions`. Файлы `robots.txt` и метатег `robots` просят поисковые системы не индексировать сайт; они не являются контролем доступа.
