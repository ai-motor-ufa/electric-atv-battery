# Исследование АКБ квадроцикла, редакция 7 — 20.09.2026

Статический сайт и инженерный PDF с общим набором исходных данных: 29 моделей, 34 конфигурации. Добавлены TENPOWER 50XG и LG E61V/E63B/E66A по открытым измерениям Batemo; LFP и смешанный NCM+LMFP (Farasis S58) исключены из расчётного каталога. Для LG отсутствующий DCIR не подменён предположением.

Сайт: https://ai-motor-ufa.github.io/electric-atv-battery/

Раздел Battery Mooch содержит 41 строку с предоставленного снимка таблицы от 11.08.2026 для 21700 ёмкостью строго более 4000 мА·ч; LG H50 включена по измеренной ёмкости при неизвестной паспортной. Реестр форума содержит 39 тем, из них шесть статей прочитаны полностью. С учётом двух новых моделей сводная таблица содержит 43 строки. Полный обход архива остановлен CAPTCHA; непроверенные статьи явно отмечены. Разные версии ячеек не объединены автоматически. Фото 58E и статья 55E сохраняются раздельно.

В `dist` доступны Excel (листы «Фото 11.08.2026», «Форум», «Методика»), три CSV (UTF-8 с BOM, разделитель `;`) и PDF от 20.09.2026. Пропуски означают отсутствие данных, а не нулевые значения. E-Scores относятся к разряду до 2,8 В; они не равны испытанной ёмкости до 2,5 В. Ограничение исходной таблицы: не распространять после 11.02.2027.

- `data.json`, `new_cells.json`: паспортные данные и источники.
- `adaptive_model.py`: расчёт мощности, энергии и усреднённой температуры при ограничениях по SOC, напряжению и температуре; результат `calculated.json`.
- `report_content.py`: общая методика и выводы.
- `build_report.py`: создаёт HTML и PDF из этих данных.
- `dist/report.js`, `dist/report.css`: сортировка, сравнение, графики и оформление.
- `photos.json`: происхождение и подписи фотографий.
- `mooch_photo.psv`, `forum_links.json`, `forum_reviewed.json`: транскрипция снимка, обнаруженные темы и извлечённые факты из прочитанных статей.
- `build_mooch_data.py`, `mooch_section.py`, `dist/mooch.js`: нормализация, выгрузки и таблица с поиском/фильтрацией.
- `build_mooch_workbook.mjs`: сборка Excel через `@oai/artifact-tool`.

Пересчёт: `python3 build_mooch_data.py`, `python3 adaptive_model.py`, затем Python с ReportLab: `python3 build_report.py`. Нужны шрифты DejaVu Sans и существующие изображения в `dist/assets`. Excel собирается отдельно при доступном `@oai/artifact-tool`: создать `/tmp/battery-workbook`, затем `node build_mooch_workbook.mjs "$PWD"`.
Проверки: `python3 validate_model.py`, `node validate_interactions.cjs`, `node validate_mooch.cjs`.

Модель служит предварительному отбору. Она не воспроизводит скоростную трассу WMTC и не заменяет тепловое испытание закрытого блока. Отсутствующий DCIR не заменяется ACIR.

Сайт публикуется из `dist` через GitHub Pages workflow. Расчётная модель и интерактивность проверяются локальными проверками, PDF и Excel — также визуальным рендерингом. Данные Batemo, оценки Mooch и паспортные значения различаются в подписях и условиях испытания.

## Проверка опубликованной редакции

На странице виден маркер `20260920-r7`. Данные выпуска и SHA-256 файлов находятся в `dist/release.json`. Универсальное ограничение тяги при 90 В удалено из модели: действуют явно описанные карты SOC и температуры, рейтинг тока и выбранный нижний предел 3,0 В на группу. Поле тока ячейки в каталоге рассчитано при номинальном напряжении конкретной сборки.

Редакция 7: выводы с фотографиями, конкретными конфигурациями и бюджетами массы; отдельный разбор оригинальных паспортов S45A и P73D. P73D добавлен отдельно от каталожного P73. Общие выводы сайта и PDF формируются из `recommendations.py`.

Уточнение редакции 7: топ-5 21700 + 3 резерва и топ-5 pouch; расчёт I²R при одинаковой условной рабочей точке, полные каталожные размеры Farasis и зазоры, охлаждение погружаемого герметичного блока.
