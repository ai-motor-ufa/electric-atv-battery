# Исследование тяговой батареи 96 В

Редакция 14, 02.10.2026. Один блок по умолчанию, три отсечки для ячеек с распределённым токосъёмом: 2,8 / 2,9 / 3,0 В. Убран общий резерв 85% энергии и ограничение мощности по уровню заряда для этих ячеек. Начало с полного заряда. Применимые токовые ограничения и наблюдаемый диапазон разрядных кривых сохранены. Для других ячеек прежняя предварительная карта по заряду и 3,0 В требуют отдельной проверки паспортом.

Нагрузки идут последовательными стадиями в повторяющемся цикле 100 с. Расчёт времени и средней температуры сценарный; точная карта КПД двигателя отсутствует. Принят КПД 88%. Наиболее горячие ячейки, двигатель и контроллер отдельно не моделируются.

Два двигателя 15/30 кВт имеют по одному независимому блоку 26S16P. Запрос задаётся на каждый двигатель. Энергия, мощность и тепло суммируются; время, температура и ток каждой ветви остаются как для одной. Отличать от двух блоков, разделяющих нагрузку одного двигателя.

Пробег отображается по двум энергетическим ориентирам BRP: 8,9 кВт·ч / 80 км по WMTC и / 50 км в средней эксплуатации. Паспортная сухая масса базовой версии — 398 кг; квадроцикл пользователя принят с той же массой. Полезная энергия BRP неизвестна, дорога и скоростной цикл не моделируются.

Главная таблица показывает лучшее предложение Alibaba для точной модели с ценой, кроме отсутствующих в наличии. Полный архив 24 исходных предложений сохранён отдельно. Фото Tenpower 50XG добавлено из вложения пользователя; происхождение и контрольная сумма в photos.json.

Сборка:

```sh
python3 adaptive_model.py
python3 calculation_audit.py
python3 build_report.py
python3 build_release.py
```

Проверки:

```sh
python3 validate_revision14.py
python3 -m http.server 8765 --directory dist
# В другом терминале:
node validate_interactions14.cjs
# При наличии браузера:
node validate_browser14.cjs
```

Для браузерной проверки нужен Playwright и Chromium. Полные значения без прореженных графиков экспортируются в dist/calculation_audit.json: 33 конфигурации, 108 сочетаний режима, охлаждения, числа блоков и отсечки. Для независимых двигателей результаты сохранены отдельно. Индивидуальные графики загружаются по требованию из dist/traces.

GitHub Pages публикует dist; версия 20261002-r14, контрольные суммы dist/release.json. Предыдущий PDF сохранён как архив. Исторические проверки validate_model.py и validate_interactions.cjs относятся к модели редакции 13.
